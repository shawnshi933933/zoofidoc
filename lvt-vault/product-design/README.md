# Product Design

Largely identical to LNT Vault: A protocol for minting and managing node-like asset derivatives (here, vesting rights). Users deposit/verify vesting details → Receive VT → Trade/Hold → Put Option → Mature redemption (burn VT to reclaim rights); integrates with DEXs for VT liquidity.

Key differences:

* Input: Vesting plans or notarized SAFT contracts instead of Node NFTs.
* Output: VT mint based on an economic model and does not involve the operation of physical mining nodes.
